Weather Mood

A responsive weather web app that lets users search for a city or 
choose from popular locations to view live temperature, humidity, wind 
speed, and current conditions. It also generates a simple weather 
mood such as Pleasant, Hot, Cold, Windy, or Uncomfortable—based 
on defined weather thresholds.
Built with React and Vite, deployed on Vercel, and powered by WeatherAPI. 
API keys are securely managed through environment variables.
